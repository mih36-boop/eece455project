Why the results matter

Original message: Both mechanisms authenticate the legitimate message.

Receiver impersonation: Bob signs using his own private key, but verification uses Alice's public key. His new HMAC succeeds because he possesses the shared secret.

Independent verification: Charlie can verify Alice's signature using her authentic public key. HMAC verification is not attempted because Charlie lacks the secret.

All cryptographic operations run locally using the browser's Web Crypto API. Part A and Part C generate independent keys. Participants and key distribution are simulated in one browser, not a real network protocol. Textbook context: Stallings (2017), Sections 12.2, 12.5, 13.1 and 13.6.
